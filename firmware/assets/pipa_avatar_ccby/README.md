# Pipa avatar

`Val_portrait_strip18.png` is the 18-frame animated portrait by KevoTheChamp.

- Source: https://opengameart.org/content/animated-portraits
- License: CC-BY 3.0
- Attribution: KevoTheChamp

The firmware uses the strip as 18 RGB565 frames with transparent pixels. The
generated header is `firmware/src/pipa_avatar_asset.h` and can be regenerated
with `python firmware/scripts/generate_avatar_asset.py`.
